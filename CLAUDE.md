# inferplot

inferplot is ggstatsplot for Python: one function call returns a publication-ready
statistical plot with the right test computed and its full results annotated
(statistic, df, exact p, effect size with CI, Bayes factor, n, multiplicity-adjusted
pairwise comparisons). The primary user is an AI coding agent writing analysis code
for a researcher; the researcher reading the figure is second. License: MIT.

Read `docs/STATUS.md` (phase checklist, open problems) at the start of every session
and update it at the end of every slice. Read these when the task needs them:

- `docs/design/SPEC.md`: API, methods per function and type, result contract, text
  formats, oracle, tolerances. Read the relevant section before implementing anything.
- `docs/design/DECISIONS.md`: every decision and why, with a change log.
- `docs/design/PLOTSALOT_AUDIT.md`: why we are not forking the closest prior package.

## Non-negotiable rules

1. IMPORTANT: ggstatsplot 1.1.4 is the acceptance test. Every statistic must match the
   R oracle within the tolerance registered in `tests/tolerances.py`. If `SPEC.md` and
   the oracle disagree, the oracle wins: fix `SPEC.md` and log it in `DECISIONS.md`.
2. Never loosen a tolerance, skip a test, or change an expected value to get a pass.
   Find out why the number differs.
3. Never fall back silently: no automatic switching of tests, no dropped arguments, no
   reduced bootstrap work, no partial results. Unsupported combinations raise
   `NotImplementedError` naming what is missing.
4. Clean-room statistics: implement methods from the papers cited in `SPEC.md`. Do not
   translate R package source code, except ggstatsplot itself (MIT; keep its notice in
   `NOTICE`). Reading R documentation and oracle outputs is fine.
5. Runtime dependencies: numpy, scipy, matplotlib, narwhals. pandas, polars and pyarrow
   are optional extras. Any other runtime dependency needs a `DECISIONS.md` entry; never
   add a GPL-licensed package (for example pingouin).
6. Library code never imports `matplotlib.pyplot`, never calls `show()`, never mutates
   global `rcParams`, and works headless.
7. Every random step takes `seed` (default 0) and records it in the result.

## Public API in brief

```python
import inferplot as ip

fig = ip.betweenstats(df, "group", "score", type="nonparametric")
fig.result.text.apa      # APA-style results sentence
fig.result.to_json()     # every number on the figure
fig.check()              # statistical and rendering problems, empty when clean
fig.save("score.svg")    # vector, editable text, result JSON embedded
```

- v0.1 functions: `betweenstats`, `withinstats`, `histostats`, `scatterstats`,
  `barstats`. Each exists three ways: top level (analyze and render),
  `ip.analyze.<name>` (returns `StatsResult`, imports no matplotlib), and
  `ip.render.<name>(result)`.
- `data`, `x` and, where the function has one, `y` are positional; everything else is
  keyword-only and named as in ggstatsplot, in snake_case (`type`, `pairwise_display`,
  `p_adjust_method`, `conf_level`, `tr`, `bf_prior`, `subject_id`, `digits`, ...).
- `type` accepts `parametric`, `nonparametric`, `robust`, `bayes` and ggstatsplot's
  aliases `p`, `np`, `r`, `bf`. The result records the canonical name.
- No `**kwargs` anywhere. Unknown keywords raise `TypeError` naming the closest valid
  one; removed ggstatsplot arguments and seaborn habits get the messages in
  `SPEC.md` §2.
- `withinstats` requires `subject_id`. Input is any eager pandas, polars or pyarrow frame
  in long format.

## Layout

| Path | Role |
| --- | --- |
| `src/inferplot/__init__.py` | public API only |
| `src/inferplot/_data.py` | narwhals boundary: columns, dtypes, missing values, level order, NumPy out |
| `src/inferplot/_validate.py` | argument checks, aliases, did-you-mean, removed-argument messages |
| `src/inferplot/stats/` | pure functions on NumPy arrays, one module per method family |
| `src/inferplot/analyses/` | `analyze_*`: data to `StatsResult` |
| `src/inferplot/result.py` | frozen result dataclasses, JSON and frame export |
| `src/inferplot/text.py` | subtitle, caption, APA sentence, alt text |
| `src/inferplot/check.py` | `result.check()` and `fig.check()` |
| `src/inferplot/render/` | matplotlib renderers, brackets, theme |
| `src/inferplot/export.py` | `save()` |
| `tests/fixtures/oracle/` | JSON fixtures generated by R; never hand-edited |
| `oracle/` | R generator and datasets; runs only in GitHub Actions |
| `tools/reference/` | independent audit implementations, used as cross-checks |

Path-scoped rules in `.claude/rules/` load automatically for statistics and rendering
code.

## How to work

- Follow the phases in `docs/STATUS.md` in order. Within a phase, work in vertical
  slices: one function and one type, end to end (stats, result, text, render, tests).
- Write the failing oracle parity test before the implementation.
- A slice is done when: its oracle parity tests pass; reference cross-checks pass where
  they exist; ruff and pyright are clean; an example renders to SVG; and
  `fig.check()` is empty for that example. Show the commands and their output in your
  summary.
- Commit after each done slice with a Conventional Commits message, for example
  `feat(betweenstats): Kruskal-Wallis with Dunn pairwise`, push, and tick
  `docs/STATUS.md`.
- End each phase with a fresh-context subagent review of the phase diff against
  `SPEC.md`. Fix correctness and spec gaps; ignore style preferences.
- Make decisions yourself and log them in `DECISIONS.md`. Stop and ask the human only
  to: publish to PyPI or TestPyPI; change a decision marked fixed; add a runtime
  dependency outside rule 5; run the agent evaluation (it spends their usage).
- The human is not a statistician. When you report, lead with what works and what is
  blocked, in plain language, with numbers.
- Keep process files to `docs/STATUS.md` and `DECISIONS.md`. No milestone sign-off
  documents, no evidence files per phase, no internal jargon in user-facing strings.
- When compacting, preserve the current phase and slice, failing tests and their
  causes, and open oracle discrepancies.

## Pitfalls

- ggstatsplot's `bf.prior` default is the number 0.707, not sqrt(2)/2. The difference
  shows in the fifth significant figure of Bayes factors.
- ggstatsplot applies Holm on top of Games-Howell p-values, which are already
  family-wise. Replicate it; do not fix it.
- SciPy's `studentized_range` and R's `ptukey` agree to about 3e-7 away from the far
  tail; there ptukey is off by up to about 5e-10 absolute, and ggstatsplot prints it
  (1.41e-9 where the exact p is 1.9e-14). Games-Howell p must reproduce ptukey; its
  tolerance is for Games-Howell only.
- Exact versus normal-approximation p-values in rank tests, and continuity corrections
  in chi-square and McNemar tests, follow R's rules for the given input. Read the
  variant from the oracle; it is part of the method, not a choice.
- Several effect-size CIs in R are one-sided by default (upper bound 1) and several
  are bootstrap-based. Match the oracle; compare bootstrap CIs against the
  high-resample reference, not exactly.
- ggstatsplot fixed result bugs in 1.1.3 (within-subject AKP, partially observed
  subjects) and 1.1.4 (empty factor levels, one-sided CIs). Fixtures must come from
  1.1.4.
- NumPy 2 scalars print as `np.float64(...)` and `np.int64` is not JSON-serializable.
  Convert to Python types at the result boundary.
- pandas 3 uses copy-on-write; never rely on mutating a view.
- matplotlib keeps SVG text editable only with `svg.fonttype="none"` and PDF text with
  `pdf.fonttype=42`. Set them in `save()` with `rc_context`.
- Do not use seaborn anywhere in this package.
